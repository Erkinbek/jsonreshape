# Сравнение двух файлов JSON (diff)

`diff` сравнивает два файла JSON или JSON Lines **запись за записью**, сопоставляя записи по ключу,
а не по строке, поэтому записи, которые были лишь переставлены, не отмечаются как изменения.

```bash
jsonreshape diff old.json new.json --key id
```

- `--key id` сопоставляет записи по их полю `id` (можно использовать любое поле или путь с точками).
- В выводе перечисляются добавленные, удалённые и изменённые записи, а для изменённых записей —
  какие поля различаются.
- `--exit-code` заставляет команду возвращать ненулевой код при наличии различий — удобно в
  конвейерах CI и скриптах:

```bash
jsonreshape diff old.json new.json --key id --exit-code
```

## В настольном приложении

Откройте один файл, затем воспользуйтесь **Сравнить…**, чтобы выбрать второй. Различия
показываются бок о бок, сгруппированные на добавленные / удалённые / изменённые, с выделенными
изменёнными полями.
