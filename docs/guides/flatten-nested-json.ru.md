# Развёртывание вложенного JSON в таблицу

Вложенные объекты и массивы плохо укладываются в CSV или таблицу базы данных. `flatten` превращает
вложенную структуру в плоские записи: вложенные объекты становятся **столбцами с точками**
(`contact.address.city`), а вложенный массив можно развернуть так, чтобы каждый элемент стал
отдельной строкой.

```bash
jsonreshape flatten data.json flat.jsonl --children-key children
```

Затем преобразуйте плоский результат в любой табличный формат:

```bash
jsonreshape convert flat.jsonl flat.csv
```

## Развёртывание вложенного массива в строки

При преобразовании прямо в таблицу вы можете развернуть (explode) один массив:

```bash
jsonreshape convert data.json table.xlsx --array-mode rows --explode orders
```

## Конструктор структуры (настольное приложение)

Для полного контроля **Конструктор структуры** позволяет перетаскивать исходные поля в выходную
форму и видеть живой предпросмотр, затем сохранить маппинг и применить его ко всему файлу:

```bash
jsonreshape apply structure.mapping.json data.json new.json
```
