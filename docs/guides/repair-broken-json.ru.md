# Исправление повреждённого / недопустимого JSON

`repair` исправляет типичные ошибки, из-за которых файл JSON становится недопустимым, чтобы его
можно было разобрать и открыть: завершающие запятые, отсутствующие или лишние скобки, ключи без
кавычек, одинарные кавычки, комментарии и усечённые окончания.

```bash
jsonreshape repair broken.json repaired.json --report fixes.csv
```

- `repaired.json` — это исправленный файл; оригинал остаётся нетронутым.
- `--report fixes.csv` записывает список всех внесённых изменений, поэтому ничего не исправляется
  незаметно.

## В настольном приложении

Когда файл не удаётся разобрать, панель ошибки предлагает кнопку **Исправить…**. Она показывает,
что будет изменено, прежде чем записать исправленный файл.

## Советы

- Затем выполните [`inspect`](../cli.md) или [`validate`](../cli.md), чтобы убедиться, что файл
  теперь допустим.
- Для файлов, которые допустимы, но имеют неправильную форму, см.
  [Развёртывание вложенного JSON](flatten-nested-json.md) и
  [Преобразование JSON](convert-json-to-csv-excel.md).
