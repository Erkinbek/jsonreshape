# Открытие и перестройка огромных файлов JSON

**jsonreshape** — это бесплатное **настольное приложение и инструмент командной строки** с
открытым исходным кодом для файлов JSON и JSON Lines (NDJSON), слишком больших, чтобы открыть их
в обычном редакторе, — от 100 MB до нескольких гигабайт.

[Установить](install.md){ .md-button .md-button--primary }
[Смотреть на GitHub](https://github.com/Erkinbek/jsonreshape){ .md-button }

![Просмотрщик jsonreshape с деревом большого массива JSON](img/main-light.png){ loading=lazy }

## Чем он отличается

- **Ничто не загружается в память целиком.** Многогигабайтный файл индексируется один раз
  (байтовые границы каждой записи), а затем читаются только те записи, которые вы просматриваете.
  Файл в 2 GB готов примерно за **3 секунды**; 10 миллионов записей сортируются за **77 секунд**,
  используя менее 400 MB оперативной памяти.
- **Исходный файл никогда не изменяется.** Правки живут в отдельном слое; сохранение атомарно
  заменяет файл, по умолчанию сохраняя резервную копию `.bak`.
- **Автономно и конфиденциально.** Ни телеметрии, ни доступа к сети — ваши данные никогда не
  покидают ваш компьютер.
- **Быстрое ядро, удобные инструменты.** Ядро на Rust с запасной реализацией на чистом Python,
  настольное окно на PySide6 и CLI для скриптов.

## Установка одной строкой

Начиная с первого релиза:

```bash
pip install jsonreshape          # CLI + Python library
pip install "jsonreshape[gui]"   # add the desktop window
```

См. [Установку](install.md) для готовых сборок под Windows, сборки из исходного кода и
необязательных дополнений Parquet / импорта.
